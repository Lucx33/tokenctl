▓▒░ juntar várias máquinas

Cada máquina exporta um resumo enxuto do seu uso (usage-<host>.jsonl: modelo, tokens, data, projeto - sem o conteúdo das conversas). Você junta esses arquivos aqui e o painel mescla e deduplica tudo sozinho.

1 · em cada máquina secundária

Rode o export para gerar o arquivo desta máquina:

uv run app.py export → cria data/usage-<host>.jsonl

2 · trazer os arquivos para cá

Arraste os usage-*.jsonl de cada máquina para a área abaixo (ou clique para escolher). Pode soltar vários de uma vez. Eles vão para a pasta data/ desta máquina.

arraste os .jsonl aqui
ou clique para selecionar arquivos

alternativa sem a interface

Copie os arquivos direto para data/ por scp, Syncthing, pen drive… O painel lê todos os data/*.jsonl automaticamente. A aba "Por máquina" aparece sozinha quando há mais de um computador.

privacidade

Tudo roda 100% local (servidor em 127.0.0.1), sem telemetria. Só são lidos metadados de uso (modelo, tokens, data, nome da pasta do projeto). Nunca o conteúdo das conversas, chaves de API, e-mail ou id de conta/usuário.
